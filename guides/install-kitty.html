راهنمای نصب و راه‌اندازی Kitty Terminal

این راهنما بر اساس تجربه واقعی نصب Kitty روی اوبونتو (GNOME, Wayland) نوشته شده و مشکلاتی که در این مسیر پیش اومد و راه‌حل‌شون رو پوشش می‌ده.

۱. نصب Kitty

نصب با اسکریپت رسمی نصب انجام شد:

sudo apt install -y curl desktop-file-utils
curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

این دستور Kitty رو در مسیر زیر نصب می‌کنه:

~/.local/kitty.app/
مشکل: این روش نصب، باینری Kitty رو به PATH سیستم اضافه نمی‌کنه. یعنی دستور kitty به‌تنهایی در ترمینال کار نمی‌کنه و باید از مسیر کامل استفاده بشه: 
~/.local/kitty.app/bin/kitty

راه‌حل: اضافه‌کردن باینری به PATH

مسیر مطلق home فقط مربوط به یک سیستم خاص است و نباید در فایل‌های desktop یا دستورات راهنما hard-code شود. برای اینکه فرمان kitty در ترمینال و فایل‌های desktop قابل اجرا باشد، یک symlink در ~/.local/bin بساز:

mkdir -p ~/.local/bin
ln -sfn ~/.local/kitty.app/bin/kitty ~/.local/bin/kitty
hash -r
kitty --version

اگر ~/.local/bin در PATH نیست، آن را به ~/.profile اضافه کن و یک shell جدید باز کن:

export PATH="$HOME/.local/bin:$PATH"

۲. تغییر نام تب (Rename Tab)

برخلاف GNOME Terminal، در Kitty یک کلید میانبر پیش‌فرض برای این کار وجود داره، ولی در فایل کانفیگ پیش‌فرض به‌صورت کامنت‌شده (غیرفعال) قرار داره:

# map --allow-fallback=shifted,ascii kitty_mod+alt+t set_tab_title

مقدار پیش‌فرض kitty_mod برابر ctrl+shift هست، یعنی کلید میانبر نهایی Ctrl+Shift+Alt+T می‌شه.

راه‌حل: فعال‌سازی دستی

mkdir -p ~/.config/kitty
echo "map ctrl+shift+alt+t set_tab_title" >> ~/.config/kitty/kitty.conf

بعد از این کار، Kitty رو ری‌استارت کن (یا با Ctrl+Shift+F5 کانفیگ رو reload کن). حالا با زدن Ctrl+Shift+Alt+T یک پرامپت پایین صفحه باز می‌شه که می‌تونی اسم جدید تب رو بنویسی.

✓ تست شد و با موفقیت کار کرد.

۳. اضافه کردن Kitty به نوار Favorites (GNOME)

بعد از نصب، Kitty در جستجوی Activities پیدا نمی‌شد و در نتیجه امکان "Add to Favorites" هم نبود. علت این بود که نصب‌کننده، فایل .desktop رو فقط داخل پوشه نصب می‌ذاره، نه در مسیری که GNOME اسکن می‌کنه.

روش پایدار برای Favorites

فایل desktop اصلی Kitty ممکنه هنگام اجرا دوباره تولید بشه؛ بنابراین آن را ویرایش نکن. یک entry مستقل بساز تا Kitty نتونه آن را بازنویسی کنه:

cat > ~/.local/share/applications/kitty-local.desktop <<EOF
[Desktop Entry]
Version=1.0
Type=Application
Name=Kitty Terminal
GenericName=Terminal emulator
TryExec=$HOME/.local/bin/kitty
Exec=$HOME/.local/bin/kitty --class kitty-local
Icon=$HOME/.local/kitty.app/share/icons/hicolor/256x256/apps/kitty.png
Terminal=false
Categories=System;TerminalEmulator;
StartupNotify=true
StartupWMClass=kitty-local
EOF
desktop-file-validate ~/.local/share/applications/kitty-local.desktop
update-desktop-database ~/.local/share/applications

در این روش باید kitty-local.desktop را به Favorites اضافه کنی، نه kitty.desktop. در Activities عبارت Kitty Terminal را جست‌وجو کن، روی آن کلیک راست کن و Add to Favorites را بزن.

تایید

برای بررسی نصب و entry:

command -v kitty
kitty --version
desktop-file-validate ~/.local/share/applications/kitty-local.desktop
test -x ~/.local/bin/kitty && echo "Kitty executable is ready"
نکته درباره Wayland: چون نشست GNOME از نوع Wayland بود، روش قدیمی ری‌استارت GNOME Shell با Alt+F2 → r کار نمی‌کنه. اگر بعد از ساخت entry جدید، Activities آن را نشان نداد، یک‌بار logout/login کن. اگر kitty-local.desktop در Favorites است ولی آیکن قبلی باقی مانده، مورد قدیمی kitty.desktop را از Favorites حذف و entry جدید را اضافه کن.
✓ بعد از این مراحل، Kitty با فرمان مستقیم، Activities و Favorites قابل اجراست.

۴. اصلاح نصب موجود و آیکن Favorites

اگر Kitty نصب است ولی آیکن آن در Favorites عمومی یا شبیه Settings دیده می‌شود، ابتدا همه‌ی پنجره‌های Kitty را ببند و این بلوک را کامل در یک ترمینال اجرا کن:

set -e
mkdir -p "$HOME/.local/bin" "$HOME/.local/share/applications"
ln -sfn "$HOME/.local/kitty.app/bin/kitty" "$HOME/.local/bin/kitty"

cat > "$HOME/.local/share/applications/kitty-local.desktop" <<EOF
[Desktop Entry]
Version=1.0
Type=Application
Name=Kitty Terminal
GenericName=Terminal emulator
TryExec=$HOME/.local/bin/kitty
Exec=$HOME/.local/bin/kitty --class kitty-local
Icon=$HOME/.local/kitty.app/share/icons/hicolor/256x256/apps/kitty.png
Terminal=false
Categories=System;TerminalEmulator;
StartupNotify=true
StartupWMClass=kitty-local
EOF

desktop-file-validate "$HOME/.local/share/applications/kitty-local.desktop"
update-desktop-database "$HOME/.local/share/applications"

favorite_apps="$(gsettings get org.gnome.shell favorite-apps)"
if [[ "$favorite_apps" == *"'kitty-local.desktop'"* ]]; then
    :
elif [[ "$favorite_apps" == *"'kitty.desktop'"* ]]; then
    favorite_apps="$(printf '%s\n' "$favorite_apps" | sed "s/'kitty.desktop'/'kitty-local.desktop'/")"
else
    favorite_apps="$(printf '%s\n' "$favorite_apps" | sed "s/]$/, 'kitty-local.desktop']/")"
fi
gsettings set org.gnome.shell favorite-apps "$favorite_apps"

hash -r
kitty --version
echo "Kitty Favorites entry repaired"

بعد از اجرای موفق، Kitty را فقط از Favorites جدید باز کن. اگر Activities هنوز آیکن قبلی را نشان داد، یک‌بار logout/login انجام بده.
